# Updating the Website

If you want to make changes directly on GitHub:

1) Create a [Pull Request](https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request) (PR) with your changes.
2) In the PR, mention @k1nho and request a review.
3) Once the changes are reviewed and approved, they will be merged and published to the website.
